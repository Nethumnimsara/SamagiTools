# Samagi Tools Website

Static responsive e-commerce site for Samagi Tools.

## Run
Open `index.html` in a browser, or serve this folder with any static web server.

## Intro video
Put your video at `public/intro-video.mp4`.

## Products
Edit the `products` array in `app.js`. Set `price: null` when the current price is unknown.

## Logo & favicon
The supplied Samagi Tools logo is `assets/logo.jpg`. Favicon files are generated from the supplied logo icon.

## WhatsApp
Orders use `+94 72 062 3232` and are generated dynamically from the cart.

## Deployment
Upload the whole folder to a static host such as GitHub Pages, Netlify, Vercel, Cloudflare Pages, or your normal hosting account.
